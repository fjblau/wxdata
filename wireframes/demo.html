BUFR Field Mapping

WMO BUFR (Binary Universal Form for Representation of meteorological data) is the global standard for upper-air and surface observations. Fields that map to a WMO Table B descriptor are immediately compatible with national met services and NWP centres (ECMWF, NOAA, DWD). Fields without a descriptor are custom payloads — the core challenge for an open radiosonde platform.

The Open Platform Challenge

This station already has 14 custom fields that fall outside WMO Table B. When StratoChaser allows researchers to mount their own payloads — radiation detectors, biological samplers, atmospheric chemistry sensors — every new sensor type adds more custom fields. The data architecture must handle this gracefully: store custom fields without breaking standard pipelines, tag them clearly, and offer a path to formal WMO registration for fields that prove broadly useful. ArangoDB's schema-flexible document model handles this natively — no migrations, no breaking changes.
