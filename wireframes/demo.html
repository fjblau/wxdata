BUFR Field Mapping

WMO BUFR (Binary Universal Form for Representation of meteorological data) is the global standard for upper-air and surface observations. Fields that map to a WMO Table B descriptor are immediately compatible with national met services and NWP centres (ECMWF, NOAA, DWD). Fields without a descriptor are custom payloads — the core challenge for an open radiosonde platform.

The Open Platform Challenge

This station already has 14 custom fields that fall outside WMO Table B. When StratoChaser allows researchers to mount their own payloads — radiation detectors, biological samplers, atmospheric chemistry sensors — every new sensor type adds more custom fields. The data architecture must handle this gracefully: store custom fields without breaking standard pipelines, tag them clearly, and offer a path to formal WMO registration for fields that prove broadly useful. ArangoDB's schema-flexible document model handles this natively — no migrations, no breaking changes.

StratoChaser domain

Above 100 hPa (~16 km) the profile reverses — the stratosphere warms with altitude. Traditional radiosondes burst before reaching here.

A reusable platform reaching 30–50 km fills a genuine observational gap for:

  • Ozone layer monitoring
  • Aviation corridor planning
  • Atmospheric drag modelling
  • Space weather coupling
  • Climate baseline data

GRAW Radiosondes — grawMet

Nuremberg, DE · professional / NMS market
graw.de ↗

Database-driven meteorological software for daily radiosonde measurements. Full suite of thermodynamic diagrams (Tephigram, Skew-T, Emagram, Stüve, Hodograph), flight map via OpenStreetMap/Bing, real-time status bar, BUFR decoder. Proprietary hardware lock-in (GS-E/U/I/B and multiSonde systems). Integrates with Sounding Center and grawGo mobile. Data export via HTTPS, FTP, SFTP, email.

Skew-T / Tephigram BUFR native Hodograph Proprietary hardware Single-use balloons Closed ecosystem
Relevance: Sets the standard for diagram formats (grawMet supports every standard thermodynamic diagram). Their BUFR decoder tool signals awareness that BUFR complexity is a pain point. Note they publish a sustainability page explicitly about the environmental impact of radiosondes — reusability is an industry pressure point.

Vaisala — DigiCORA / RS41

Vantaa, FI · dominant NMS / WMO market leader
vaisala.com ↗

Global market leader in upper-air sounding. RS41 series is the WMO reference sonde; DigiCORA software handles multi-sounding, automated workflows, real-time relay, secure data transfer. Deep integration with national met service infrastructure. MetGRAPH add-on provides thermodynamic diagrams. Entirely proprietary — hardware, software, and data pipeline are vendor-controlled. Extremely expensive per-launch cost.

WMO reference standard Multi-sounding Proven NMS deployment Proprietary lock-in High per-launch cost No open payload
Relevance: The benchmark every NMS buyer compares against. StratoChaser doesn't need to beat Vaisala on established NMS workflows — the opening is in research institutions, universities, and emerging economies priced out of Vaisala's ecosystem. Open payload + reusability = different buyer.

TU Wien — IGRA2 Visualization Tool

Vienna, AT · academic / open source · 2021
cg.tuwien.ac.at ↗

Python/Plotly/Dash visualization of the IGRA2 global radiosonde archive (~3,000 stations, records from early 1900s to near-real-time). Geo-scatter maps, time-range sliders, station data tables, temperature time series at 1000 hPa. Built on the comparative geospatial visualization technique of Janicke et al. (2012). Open source, research-grade, not production software. Illustrates the depth of the historical dataset available for benchmarking.

Open source IGRA2 archive (3000+ stations) Historical depth (100+ years) Python / Plotly / Dash Research only, not production No real-time ingestion
Relevance: Demonstrates appetite for interactive radiosonde visualization in academic settings. The IGRA2 dataset is the natural historical baseline for any new radiosonde platform — StratoChaser data should eventually contribute to it. Austrian academic origin is directly relevant to the local ecosystem.

RMetS — Geoscience Data Journal (2025)

Royal Meteorological Society · doi:10.1002/gdj3.70034
rmets ↗

Peer-reviewed publication in the Royal Meteorological Society's Geoscience Data Journal (2025) addressing radiosonde data standardisation, archiving, or visualization — the GDJ focus is specifically on making geoscience datasets FAIR (Findable, Accessible, Interoperable, Reusable). The journal publishes data description papers that establish community standards for how atmospheric observation data should be structured, documented, and shared.

FAIR data principles Peer-reviewed standard RMetS / WMO aligned 2025 publication
Relevance: FAIR data compliance is increasingly a requirement for publicly-funded atmospheric research. A StratoChaser data architecture built on FAIR principles from day one (documented schema, BUFR compliance, open API, persistent identifiers) positions it for EU Horizon and WMO data-sharing mandates. Multi-model DB supports FAIR natively.

CPAS / ClusterTech — Skew-T Log-P MOOC Module

Hong Kong Science Park · atmospheric modelling + education · NWP/MPAS-A focus
cpas.earth ↗

ClusterTech's CPAS platform (Cloud-based Parallel Atmospheric Simulation) includes a MOOC module specifically on Skew-T log-P visualization of radiosonde data. Their core product is NWP/atmospheric modelling (competing with WRF and MPAS-A). The educational module positions Skew-T diagrams as the standard interface between raw radiosonde data and model initialization — exactly the data flow StratoChaser's architecture needs to support.

The Gap StratoChaser Fills

🌍 Accessibility

Vaisala and GRAW serve national met services with five- and six-figure budgets. Universities, NGOs, and research teams in emerging markets are priced out. A reusable, open platform changes the economics of upper-air observation.

🧪 Open Payload

No existing commercial platform lets researchers mount their own sensors. Every new measurement type requires buying a new proprietary instrument. StratoChaser's open platform makes the radiosonde a research vehicle, not just a weather instrument.

📊 Data Architecture

Existing tools store data in proprietary databases or flat files. A FAIR-compliant, multi-model architecture (document + graph + KV) with BUFR mapping, open REST API, and flexible custom-payload schema is a first-principles rebuild of the radiosonde data stack.

AQL — cross-payload query example
FOR f IN payload_files
  FILTER f.capture.altitude_m > 10000
     AND f.thermal.temp_max_C > 15
     AND f.tags ANY == "ground-surface"
  FOR v IN 1..1 OUTBOUND f
      captured_during
  FILTER v.conditions.fire_risk == "high"
  RETURN {
    file: f.file.name,
    alt:  f.capture.altitude_m,
    tmax: f.thermal.temp_max_C,
    flight: v._key
  }
Why multi-model matters for binary assets
  • Binary stored externally (MinIO/S3) — only metadata in DB
  • Graph links file → flight → level → region without joins
  • Schema-free: HDF5 metadata differs from GeoTIFF — no migrations
  • KV cache: latest fire-risk tile per region, sub-ms reads
  • BUFR status field on every asset — NMS compliance audit trail
